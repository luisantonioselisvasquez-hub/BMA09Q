## Grupo 4: Backtracking

- **Concepto de Backtracking:** Definición de esta estrategia y características principales para explorar posibles soluciones.

- **Espacio de búsqueda:** Explicación del conjunto de posibilidades que pueden ser exploradas durante la búsqueda de una solución.

- **Construcción de soluciones:** Explicación de cómo se construyen progresivamente las posibles soluciones y cómo se toman las decisiones en cada etapa.

- **Poda:** Explicación de cómo se descartan caminos que no pueden conducir a una solución válida o conveniente.

- **Fuerza bruta vs Backtracking:** Comparación entre ambas estrategias y explicación de cómo Backtracking permite reducir la cantidad de posibilidades exploradas.

- **Permutaciones:** Aplicación de Backtracking para generar y explorar permutaciones.

- **Combinaciones:** Aplicación de Backtracking para generar y explorar combinaciones.

- **N-Reinas:** Aplicación de Backtracking para resolver el problema de colocar N reinas en un tablero sin que se amenacen entre sí.

- **Sudoku:** Aplicación de Backtracking para resolver un Sudoku mediante la exploración y poda de posibles soluciones.
